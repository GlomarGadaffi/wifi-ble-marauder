Pure ESP-IDF 6.0.1 WiFi and BLE security research tool. No Arduino. No wrappers. Rewritten from the ground up in C against the native IDF stack.

Beyond Arduino Limits: The Native IDF Paradigm

Legacy microcontroller tools (like Arduino Marauder) are constrained to a single thread, 2.4 GHz legacy radios, and 31-byte advertising payloads. wifi-ble-marauder rewrites the entire toolchain against native ESP-IDF 6.0.1, unlocking 5 GHz frame injection on ESP32-C5, WiFi 6 (802.11ax) frame crafting, Thread 1.3 / Matter intercept on ESP32-C6, and 254-byte BLE 5.0 extended advertising.
